# Матриця трасування

## 1. Промт
> Побудуй двосторонню матрицю трасування (Traceability Matrix) для системи Hotel-reservation-system, яка пов'язує всі EARS-вимоги (REQ-01…REQ-29), поведінкові Gherkin-сценарії (SC-01…SC-29), Use Cases (UC-01…UC-12) та User Stories (US-01…US-11). Окремо виділи непокриті вимоги та надай обґрунтування.

## 2. Що видала AI
AI побудувала таблицю відповідності між вимогами, сценаріями та Use Cases. Проте:
1. Було пропущено стовпчик ізв'язку з User Stories (US).
2. AI намагалася штучно прив'язати вимогу REQ-08 (неподільність) до звичайного Gherkin-сценарію, хоча послідовні сценарії не тестують паралельні гонки.

## 3. Що виправлено
* **Додано стовпчик User Stories:** Інтегровано зв'язки з US-01…US-11 для повної простежуваності від потреб користувача до технічних вимог.
* **Коректне оформлення непокриття:** Вимогу REQ-08 офіційно позначено як "не покриту" Gherkin-сценаріями та винесено в окреме обґрунтування (оскільки вона перевіряється інтеграційним тестом із паралельними запитами).
