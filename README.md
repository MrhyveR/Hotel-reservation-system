# Hotel-reservation-system | Система Бронювання Готелів

## Про проєкт

**Hotel-reservation-system** - платформа для управління бронюванням номерів у готелі. Гість обирає вільні дати та тип номеру, здійснює безпечну оплату через платіжний шлюз, а адміністратор контролює завантаженість номерного фонду й статуси кімнат.

## Ролі

| Роль | Що робить |
| :--- | :--- |
| **Guest** | Шукає номери, обирає дати заїзду/виїзду та створює бронювання |
| **Payment Gateway** | Зовнішній сервіс, що обробляє транзакції та підтверджує оплату |
| **Admin** | Керує станом номерів, цінами та статусами обслуговування |

## Як це працює

1. Гість обирає дати заїзду/виїзду та тип номеру у системі.
2. Система перевіряє доступність номерів та ініціює запит на оплату.
3. Платіжний шлюз обробляє транзакцію та повертає статус платежу.
4. У разі успішної оплати система створює бронювання та надсилає підтвердження на email.
5. Адміністратор за необхідності переводить номери у статус технічного обслуговування.
